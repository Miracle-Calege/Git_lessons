1.Metodo

No momento da execucao do script: bash -x ./nome do script

ex: bash -x ./myFirstScript

NB:Executa passo a passo o script exibindo no terminal


2.Metodo 

Colocar-x cabeçalho do script

ex: #!/usr/bin/bash -x

NB:Executa passo a passo o script exibindo no terminal
